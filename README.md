# Gestion de pension
Ceci est une application Desktop construit avec JAVA développée pour gérer les pensions et les informations associées aux personnes concernées. 
Le projet permet de centraliser les données et de faciliter leur consultation et leur gestion à travers une 
interface graphique.

##Fonctionnalités :
- Ajouter, modifier et supprimer une pension
- Gérer les informations des personnes et des conjoints
- Gérer les paiements
- Consulter les pensions et leurs informations
- Rechercher et consulter les données enregistrées
- 
##Technologies utilisées :
- Java
- JavaFX / FXML pour l'interface graphique
- PostgreSQL pour la base de données
- Spring Boot pour l'API REST
